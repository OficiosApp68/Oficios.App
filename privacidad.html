Politica de Privacidad

Esta politica explica que datos se usan en esta primera version de OFICIOS APP y para que se usan.

La informacion publica del perfil se muestra para que otras personas puedan conocer y contactar al profesional. La contrasena y la sesion son administradas por Supabase Auth.

1. Datos que se solicitan

Para crear una cuenta se solicita email y contrasena. Para publicar un perfil profesional se solicita nombre, oficio, telefono, zona, descripcion y, si el profesional lo decide, una foto.

2. Datos visibles en el directorio

El nombre, oficio, zona, descripcion, foto y boton de WhatsApp pueden mostrarse publicamente cuando el perfil este aprobado.

3. Datos que no se publican

OFICIOS APP no muestra contrasenas, tokens de sesion, identificadores tecnicos internos ni claves privadas.

4. Uso de los datos

Los datos se usan para registrar cuentas, permitir que el profesional edite su perfil, revisar perfiles antes de publicarlos y mostrar el directorio publico.

5. Servicios externos

La autenticacion, base de datos y almacenamiento de fotos funcionan con Supabase. El contacto por WhatsApp se realiza fuera de OFICIOS APP.

6. Seguridad

El proyecto usa autenticacion y reglas de acceso de Supabase. Ninguna clave administrativa debe estar en el navegador ni en archivos publicos del proyecto.

7. Eliminacion o correccion

Si una persona necesita corregir, ocultar o eliminar informacion de un perfil, puede escribir a oficios.app68@gmail.com.

8. Etapa actual

Esta es una politica inicial para una version de prueba. Antes de lanzar a mayor escala, debe revisarse y completarse con asesoramiento legal adecuado.
